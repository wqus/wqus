## Избранные проекты

### Math Helper

Telegram-бот для решения математических задач с использованием локальных LLM.

**Что реализовано:**

* Полностью асинхронный backend
* Clean Architecture
* PostgreSQL + SQLAlchemy 2.0 Async
* Redis для кэширования и rate limiting
* RBAC-система ролей
* Telegram Stars монетизация
* Ticket System
* Cursor Pagination
* Docker-контейнеризация
* GitHub Actions CI/CD
* Unit + Integration тестирование (70%+ покрытия)
* Интеграция Ollama через приватную сеть Tailscale
* Деплой на Linux VPS

**Стек:** Python, aiogram, PostgreSQL, Redis, Docker, Pytest, GitHub Actions, Ollama

https://github.com/wqus/math_service

---

### Finly API

REST API для управления личными финансами.

**Что реализовано:**

* JWT Authentication
* Access / Refresh Tokens
* CRUD для финансовых операций
* Автоматический пересчёт баланса
* Разделение на слои API → Services → Repositories
* PostgreSQL индексация
* Docker Compose
* Alembic миграции

**Стек:** FastAPI, PostgreSQL, SQLAlchemy 2.0, Alembic, Docker

https://github.com/wqus/finly-api

### Device Statistics Analytics API

Сервис аналитики устройств, разработанный в рамках отбора на стажировку «ДИП:КОД» от Газпром нефти.

**Возможности:**

* Аналитические запросы:

  * min
  * max
  * count
  * sum
  * median
* Фильтрация по временным диапазонам
* PostgreSQL оптимизация
* Docker Compose
* Alembic миграции

**Нагрузочное тестирование:**

* 500 concurrent users
* ~226 RPS
* p95 ≈ 500 ms
* 0% failures

🔗 https://github.com/wqus/dip_code_test_api
